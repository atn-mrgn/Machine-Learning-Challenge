# Feedback Prize - Evaluating Student Writing

## Overview
The goal of this competition is to develop an automated system capable of analyzing student essays (from grades 6 to 12) to identify and classify key argumentative and rhetorical elements — such as thesis statements, supporting claims, and evidence.
Organized by **Georgia State University** and **The Learning Agency Lab**, the challenge aims to improve the quality and accessibility of automated writing feedback tools, especially for under-resourced schools. Participants will work with the largest publicly available dataset of student writing to apply their **natural language processing (NLP)** skills and help make writing instruction more effective and equitable.

## My Solution
In this work, I explored several natural language processing concepts such as word2vec, doc2vec, and NER.
Ultimately, the solution developed uses an innovative approach with an image segmentation model (Yolo-V5) that I modified to segment something else (text).
Several Python libraries and packages were used:
- Tensorflow
- Sklearn
- OpenCV
- Gensim
- etc.
The final file is: fdp-yolo-submit.ipynb
