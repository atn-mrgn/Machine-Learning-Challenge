# Machine Learning Challenges & Applied AI Projects

Welcome to my Machine Learning repository.

This repository brings together a collection of machine learning experiments, predictive modelling projects, and data science competition notebooks developed over the years.

My work explores different applications of machine learning and artificial intelligence, ranging from financial transaction classification and agricultural yield estimation to time-series forecasting, natural language processing, recommendation systems, and computer vision.

The repository includes exploratory analyses, feature engineering experiments, model development, and selected competition starter notebooks.

## Areas of Exploration

### 1. Classification & Financial Data

- [Alvin Smart Money Management Classification Challenge](./Alvin-Smart-Money-Management-Classification-Challenge/) — Exploratory analysis and machine learning experiments involving merchant and transaction categorization.
- [Credrails Banking Transaction Categoriser Challenge](./Credrails-Banking-Transaction-Categoriser-Challenge/) — Banking transaction analysis, category mapping, feature engineering, and classification.
- [UmojaHack Africa 2022 – Monthly Insurance Claim Prediction](./UmojaHack22/umojahack-africa-2022-intermediate-challenge/) — Predictive modelling exploration for short-term insurance claims.

### 2. Regression & Predictive Modelling

- [Digital Green Crop Yield Estimate Challenge](./Digital-Green-Crop-Yield-Estimate-Challenge/) — Agricultural yield estimation, exploratory data analysis, feature engineering, and feature selection experiments.
- [Fossil Stock Forecasting Challenge](./Fossil-Stock-Forecasting-Challenge/) — Time-series forecasting experiments using LSTM networks and multi-step prediction approaches.
- [Juniper Networks Global AI Challenge](./Juniper-Networks-Global-AI-Challenge/) — Regression modelling experiments for retail and sales-related metrics using ensemble learning methods.
- [Cryptocurrency Price Prediction Challenge](./Cryptocurrency%20Price%20Prediction%20Challenge/) — Predictive modelling experiments with financial time-series data.
- [Kaggle G-Research Crypto Forecasting Challenge](./%5BKaggle%5D%20G-Research%20Challenge/) — Exploratory work on cryptocurrency forecasting and time-series patterns.

### 3. Natural Language Processing & Recommendation Systems

- [Kaggle Feedback Prize – Evaluating Student Writing](./%5BKaggle%5D%20Feedback%20Prizes%20Challenge/) — Experiments in NLP, Word2Vec, Doc2Vec, named entity recognition, and an adapted YOLOv5-based approach to text segmentation.
- [Hulkshare Recommendation Challenge](./Projet%20Hulkshare%20Recommendation/) — Music recommendation experiments based on users' listening behaviour and song-related features.
- [Zindi New User Engagement Prediction Challenge](./Zindi-New-User-Engagement-Prediction-Challenge/) — User activity analysis, behavioural feature aggregation, and next-month engagement prediction.

### 4. Computer Vision, Sensor Analytics & Deep Learning

- [Modified YOLOv5](./Modified_Yolo/) — Object detection experiments based on the YOLOv5 codebase.
- [Sensor Fusion – Smoke Detection Classification](./Sensor-Fusion-Smoke-Detection-Classification/) — Classification experiments using sensor measurements to identify fire alarm conditions.
- [UmojaHack Africa 2023 – Cryptojacking Detection](./UmojaHack23/Intermediate/) — Exploratory analysis and classification of cryptojacking-related activity.
- [UmojaHack Africa 2023 – Rubik's Cube](./UmojaHack23/Advanced/) — Exploration of a reinforcement-learning environment for training agents to solve a Rubik's Cube.
- [Topcoder Skill Builder – Advanced Data Science](./Topcoder-Skill-Builder-Competition%20-%5BAdvanced%20Data%20Science%5D-%5BHost%20Competition%5D/) — Exploratory analysis, preprocessing, feature engineering, and deep learning experiments.

### 5. Education, Environment & Social Impact

- [DataDrive2030 – Early Learning Predictors Challenge](./DataDrive2030-Early-Learning-Predictors-Challenge/) — Exploration of predictive modelling and model interpretability for early-learning outcomes.
- [UmojaHack Africa 2023 – EY Carbon Prediction](./UmojaHack23/Beginner/) — Starter notebook and initial exploration of a carbon prediction challenge.
- [Environmental Data Hackathon](./hackaton/) — Exploratory statistical analysis and predictive modelling involving PM2.5 measurements.

Some of the techniques explored throughout these projects include:

- Data preprocessing and missing-value treatment.
- Feature engineering and feature selection.
- Supervised classification and regression.
- Ensemble learning and gradient boosting.
- Time-series analysis and forecasting.

- Natural Language Processing and text representation.
- Recommendation systems and user behaviour modelling.

- Model interpretability.

## Repository Structure

Projects are organized into separate folders according to their respective challenges or problem domains.

Each folder may contain Jupyter notebooks, Python scripts, exploratory analyses, model experiments, and supporting materials.

## Notes on Reproducibility

- Some competition datasets are not included in this repository and must be obtained from their respective official sources.
- Dependencies may vary between projects.
- Some folders contain starter notebooks, tutorials, or intermediate experiments rather than complete end-to-end solutions.
- Third-party codebases and competition materials retain their original attribution and licensing requirements.

This repository is primarily a record of applied machine learning exploration and practical experimentation. It does not imply that every project represents a completed competition submission or a deployed model.
